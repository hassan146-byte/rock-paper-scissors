# rock-paper-scissors

First project using javascript. 

Will create blank html file which is then linked to a js file. 

Objective is to create a game of rock paper scissors played in the console. Will create a function to randomly return "rock" "paper" "scissors".

Then write a function that takes the user choice and returns it. 

Write another function that plays a single round, logs the winner, and increments the score. 

Write another function to play the entire game of 5 rounds, keeps track of the scores and declares a winner at the end. 

Will write pseudocode algorithms to work out how best to structure the code and work out any flaws in the logic early on to reduce time wasted on incorrect code.
